# 朗文六版英汉 MDX 检查

检查日期：2026-09-20。原文件只读，没有接入插件或修改词典。

## 结论

这份文件具有可解析的文字、Unicode 音标和较明确的 HTML 语义标签，技术上明显优于扫描 PDF 路线，值得用作 Folio 数据适配试验。但中文覆盖有实际缺口，尚不适合认定为完整英汉词库。建议向提供者核对 `fish`、`propagation`、`refraction` 的中文缺失，再决定是否用作主词库。

文件头为 MDict 2.0、HTML、UTF-8，创建日期字段为 2020-3-7。标题及描述字段为空；这些信息无法验证出版社来源、版本真实性或授权。

完整遍历 MDX 得到 265,545 条索引记录，其中 212,797 条为 `@@@LINK=` 跳转，52,748 条为非跳转记录。不能将索引总数宣传为独立单词数量。解压后的词条正文合计约 1.20 GB（十进制），包含大量例句、拓展内容和 HTML；这不是 Folio 精简数据库的体积，也不是查词所需内存。

在 52,748 条非跳转记录中，36,483 条含基本汉字区字符，16,265 条没有（约 30.84%）。这是记录级字符检查，不是中文义项完整率：含中文不代表每个义项都有译文，记录也未必对应唯一主词。

## 适配 Folio 的可行性

样本中可辨识 `pron`、`pos`、`sense`、`def`、`lexunit`、`phrvbhwd`、`colloc` 等类。双解释义常使用 `en` 和 `tran` 子标签，便于分离英文与中文，而不用 OCR 或 AI 猜测句子边界。

不过不能全局抽取所有 `.def` / `.pos` / `.pron`：正文同时嵌套同义词、搭配、其他词条例句和派生词，会造成归属混乱。应先识别主词条与拓展模块，再保留主词、音标、词性、中文义项及所需短语。处理词条跳转、派生词定位、词组索引和缺译回退也属于适配工作。

全部非跳转正文含脚本标签。原 HTML 引用 `ldoce6ec.js` 和 `ldoce6ec.css`，MDD 内存在前者，外部 CSS 文件名则为中文。外部 CSS 还引用了 MDD 中未发现的 Optima 字体。直接复刻原展示可能需要资源路径修正；使用 Folio 自有展示样式可以避开这类样式依赖。解析时不需要执行词典脚本。

## 可复核材料与限制

- `audit_mdx.py`：只读检查脚本；依赖本次下载到项目 tmp 目录的 readmdict 0.1.1，以及 Python 环境中的 BeautifulSoup。
- `audit.json`：索引统计、目标样本摘要、资源统计。
- `samples.raw.json`：25 个命中查询对应的原始正文样本。
- `entries-without-chinese.json`：未检出基本汉字区字符的非跳转记录名称。
- `resource-keys.json`：资源索引名称。

此检查没有对照原书逐义项校勘，也没有核实来源、授权、所有别名目标、所有资源引用或音频可播放性。readmdict 的正文解码使用其默认忽略无效编码字节行为，不能以本次遍历成功证明每一个原始字节都无损。音标正常的判断限于已查看样本。

## 补充：中文与英文释义配对检查

再次遍历全部 MDX，对 HTML 中 `.def` 下含中文的 `tran` 节点检查对应的 `en`。共检出 90,557 个带中文的释义节点，其中 90,556 个有包含英文字母的英文栏；唯一未通过字母检测的节点是 `threescore`，其英文栏为数字 `60`，中文为“六十”，人工查看结构后确认并非缺少英文栏。因此，在此次识别范围内，所有带中文的释义节点都有非空对应英文栏。

该统计包括拓展模块，不代表 90,557 个独立主词义项，也不是对译文准确性的验证。412 条非跳转记录没有标准 `.def` 节点，未纳入义项配对判断，转换时需单独处理其结构。结果见 `bilingual-check.json`，脚本为 `check_bilingual.py`。

若用户接受英文释义回退，这份词典可作为首版主数据源候选，不必将中文未覆盖视为整条词条不可用。建议按义项处理：有中文显示中文并保留英文供展开；没有中文显示原有英文，并轻量标注“英文释义”。真正未收录或无法定位的条目另行处理，不自动生成译文。该方案仅为讨论建议，尚未实施插件功能。
