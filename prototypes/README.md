# 词典 UI Demo

这是独立的视觉与交互原型，用于比较设计方向，尚未实现 Chrome 扩展或真实词典查询。所有文章和词条均为内置演示内容，无外部依赖，也不会请求 AI 或产生接口费用。

2026-09-20：真实插件已在项目根目录实施，安装和导入方式见根目录 `README.md`。本目录继续保留为最初的设计参考。

直接用浏览器打开 `dictionary-ui.html` 即可。也可在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 <http://127.0.0.1:8765/dictionary-ui.html>。

## 三种方向

**当前选定方向：Folio / 笺。** 用户在比较后明确表示更喜欢第二版 Folio。后续 UI 打磨以此版为基础；具体尺寸、字体和细节仍可调整，尚未进入插件功能实现。Demo 未指定版本时默认展示 Folio，另外两版保留作比较。

| 方向 | 特点 | 取舍 |
| --- | --- | --- |
| Quiet / 静 | 326 px，紧凑排版、实色背景、细边框 | 遮挡较少，内容多时更密集 |
| Folio / 笺 | 386 px，衬线词头、编号释义、暖纸色背景 | 阅读舒展，但占用空间更多 |
| Mist / 雾 | 364 px，轻磨砂背景、独立释义底板、纵向词组 | 层次柔和，长词条会增加卡片高度 |

窄窗口时卡片会缩小至可用宽度；高度不足时支持内部滚动。

## 操作

- 底部切换设计方向，或按 `1` / `2` / `3`、左右方向键。地址参数 `?v=1`、`?v=2`、`?v=3` 可直接打开对应设计。
- 顶部切换明暗背景、英文随笔 / 学术文章，以及三个示例词条。
- 点击正文中标记的单词唤起词典；也可选中内置示例词后按 `Enter`。这里只演示交互，不代表最终快捷键决定。
- `run` 词条支持展开、收起更多释义。
- 点击卡片外、关闭按钮，或按 `Esc` 收起。
- 点击“重新显示词典”、底部重播按钮，或按 `R` 重新展示。

已检查三种设计的实际渲染、明暗主题、词条与场景切换、多义词展开、键盘切换、关闭和重新唤起；检查了 1280 × 900 桌面及 390 × 844 窄窗口布局。检查结束时浏览器未报告控制台错误或警告。
