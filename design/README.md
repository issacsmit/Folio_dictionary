# Folio 产品图标

`folio-icon-original.png` 是用户于 2026-09-20 指定的原图，按原文件完整保留。

`folio-icon.png` 是当前产品使用的版本：用户认为淡化后的阴影仍然过散，因此通过内置 imagegen 移除黑色旋纹在底座表面形成的局部灰影，改为平面印刷效果，只保留底座外侧投影。编辑提示要求保持图形轮廓和构图不变。完整提示见 `icon-edit-prompt-v2.md`；前一版提示保留在 `icon-edit-prompt.md`。

在 Windows PowerShell 中执行 `./scripts/icons.ps1` 可从当前版本等比导出 `icons/` 中的 16、32、48、128、256 px PNG。扩展管理页、工具栏、扩展页面标签和设置页/弹出页品牌图标均使用这些资源。原始大图不进入发布 ZIP。

词条顶部复用 `icons/256.png`，在 28 px 的展示区域内通过 CSS 定位仅展示旋纹，隐藏方形底座和外围投影。图标居左，品牌文字靠右，品牌行与词头仅留 9 px 间距。浅色使用 multiply 融合纸色，深色经反相后使用 screen；这不修改源图或其他位置的完整图标。该单个图标资源通过动态扩展资源地址提供给网页卡片。
